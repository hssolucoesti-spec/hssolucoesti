# HS Soluções TI — Landing Page

Landing page independente, recriada em React + TypeScript + Vite + Tailwind CSS.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Observações

- O diretório `.bolt` foi removido.
- A aplicação não depende de serviços do Bolt para funcionar.
- O código da landing page está em `src/`.
- Contatos e links principais ficam em `src/lib/constants.ts`.
